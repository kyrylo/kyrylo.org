Run it yourself.

Requires Rust 1.96+ 
cargo install --git https://github.com/kyrylo/feeds --locked --bin feeds
Set your password & start

Choose a password with at least 12 characters (Bash/Zsh):

export SECRET_KEY_BASE="$(openssl rand -hex 64)"
printf 'Owner password: '
IFS= read -r -s feeds_password
printf '\n'
export FEEDS_PASSWORD_HASH="$(printf '%s' "$feeds_password" | feeds hash-password)"
unset feeds_password
mkdir -p storage
feeds

Open localhost:3000, sign in, and create a feed in connect. Keep the same session secret in your service’s environment and keep the storage/ directory between restarts. Your password is saved in the database.

Also runs with Docker or Kamal.

Send your first event

Each feed has its own private URL. Copy it from connect, then send some JSON:

curl 'https://your-feeds.example/api/v1/feeds/YOUR_TOKEN/events' \
  -H 'Content-Type: application/json' \
  -d '{"event":"deployed","emoji":"🚀","text":"My project is live"}'

Only text is required. Add properties when you need more detail, search when you need to find something, and let new events arrive as you work.

Hey there,

I like knowing what my projects are up to. Someone signed up. A payment came in. A deploy finished.

This started as Telesink, a product I planned to sell. But what I wanted was a small, personal place to watch those things happen. So I made it Feeds.

It’s a live text log with a feed for each thing you want to follow. A bit of IRC, a search box, and the details when you need them.

Like Owlytics, it runs on Rust and SQLite. One executable, one database file, and your own server. No subscription.

I use it for my projects. It’s open source under MIT, ready for yours.
