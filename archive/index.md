<dl class="project-list">
  <dt><a href="/htmlmaze/">The HTML Maze</a></dt>
  <dd>
    A shared, anonymous web experiment with 500 generated rooms, preserved as a read-only static archive after the Rails server was retired in July 2026.
  </dd>

  <dt><a href="https://github.com/kyrylo/ablaze-theme-vscode">Ablaze</a></dt>
  <dd>
    A minimalist color theme for Visual Studio Code that burns softly.
  </dd>

  <dt><a href="https://matcharoo.app">Matcharoo</a></dt>
  <dd>
    A word association game where you match similar words, learn new words easily, and have a blast with friends as you discover who knows the most (<a href="{% post_url 2024-02-21-i-built-a-word-matching-game-called-matcharoo %}">blog post</a>).
  </dd>

  <dt><a href="https://coffeeworldrush.com">Coffee World Rush</a></dt>
  <dd>
    A leaderboard for coffee drinkers all around the world (<a href="{% post_url 2024-03-20-coffee-world-rush-a-leaderboard-for-all-coffee-drinkers-around-the-world %}">blog post</a>).
  </dd>

  <dt><a href="https://pry.github.io/">Pry REPL</a></dt>
  <dd>
    The featureful development console for Ruby.
  </dd>

  <dt><a href="https://github.com/airbrake/airbrake-ruby">Airbrake Ruby</a> and <a href="https://github.com/airbrake/airbrake">Airbrake</a></dt>
  <dd>
    The notifier libraries for the Airbrake error monitoring service, which I rewrote from scratch and maintained for many years.
  </dd>

  <dt><a href="https://github.com/kyrylo/netstring">netstring</a></dt>
  <dd>
    A Go package for formatting byte strings using declarative notation to indicate the string's size.
  </dd>

  <dt><a href="https://github.com/kyrylo/linenoise-rb">linenoise-rb</a></dt>
  <dd>
    A Ruby wrapper for <a href="https://github.com/antirez/linenoise">Linenoise</a>, a small self-contained alternative to Readline and libedit.
  </dd>

  <dt><a href="https://github.com/kyrylo/system_browser_client">System Browser</a></dt>
  <dd>
    A desktop app for browsing Ruby code, inspired by Smalltalk. Click to view details about a module or class, explore its namespace, or see the source of a method.
  </dd>

  <dt><a href="https://github.com/kyrylo/fast_method_source">Fast Method Source</a></dt>
  <dd>
    An extremely fast Ruby C extension for querying methods, procs, and lambdas for their source code and comments.
  </dd>

  <dt><a href="https://github.com/kyrylo/system_navigation">System Navigation</a></dt>
  <dd>
    A Ruby library that provides navigation and introspection capabilities for Ruby programs, similar to those in Smalltalk.
  </dd>

  <dt><a href="https://github.com/kyrylo/rmarshal">RMarshal</a></dt>
  <dd>
    An Erlang library for deserializing Ruby objects dumped by Marshal.dump into Erlang terms.
  </dd>

  <dt><a href="https://github.com/kyrylo/multitrap">multitrap</a></dt>
  <dd>
    A Ruby library that allows <code>Signal.trap</code> to execute multiple callbacks
  </dd>

  <dt><a href="https://github.com/kyrylo/pry-theme">Pry Theme</a></dt>
  <dd>
    A plugin for the <a href="https://pry.github.io">Pry REPL</a> in Ruby that allows customizing Pry colors using prytheme.rb files.
  </dd>

  <dt><a href="https://github.com/kyrylo/patience">Patience</a></dt>
  <dd>
    Solitaire card game built in Ruby with the <a href="https://github.com/Mon-Ouie/ray">Ray</a> library.
  </dd>

  <dt><a href="https://store.kde.org/p/1106257">Pixelate</a> and <a href="https://store.kde.org/p/1106254">Pixelnine</a></dt>
  <dd>
    Skins for the KDE terminal emulator, <a href="https://apps.kde.org/yakuake/">Yakuake</a>.
  </dd>

  <dt><a href="https://github.com/kyrylo/oramaps">OpenRA maps</a></dt>
  <dd>
    A collection of maps for the <a href="https://www.openra.net/">OpenRA</a> real-time strategy game. Some of the maps were included in the official release.
  </dd>

  <dt><a href="https://github.com/kyrylo/openra-microcontrol">openra-microcontrol</a></dt>
  <dd>
    A minigame for the <a href="https://www.openra.net/">OpenRA</a> real-time strategy game written in Lua.
  </dd>

  <dt><a href="https://github.com/kyrylo/entooru">Entooru</a></dt>
  <dd>
    Translations of random English articles about Ruby into Russian.
  </dd>

  <dt><a href="https://store.kde.org/p/1000580">Your tea, buddy</a></dt>
  <dd>
    A KDE splash screen with a white background, red text, and a small loading progress bar beneath the text. Pairs well with the <a href="https://store.kde.org/p/997993">Already awake?</a> KDM4 theme.
  </dd>

  <dt><a href="https://store.kde.org/p/997993">Already awake?</a></dt>
  <dd>
    A <a href="https://en.wikipedia.org/wiki/KDE_Display_Manager">KDM4</a> theme with a white background and red text. Pairs well with the  <a href="https://store.kde.org/p/1000580">Already awake?</a> splash screen.
  </dd>

  <dt><a href="https://github.com/kyrylo/bash-completion-subtle">bash-completion-subtle</a></dt>
  <dd>
    Bash completion scripts for <a href="https://subforge.org/projects/subtle">Subtle WM</a> and its tools.
  </dd>

  <dt><a href="https://github.com/kyrylo/zsh-completion-subtle">zsh-completion-subtle</a></dt>
  <dd>
    Z Shell completion scripts for <a href="https://subforge.org/projects/subtle">Subtle WM</a> and its tools.
  </dd>
</dl>
